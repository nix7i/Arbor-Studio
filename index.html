Navigation
Drag the background to pan. Mouse wheel zooms at the cursor. Drag nodes to move them (hold Alt to bypass snapping).
Connecting
Press C (or the Connect button), click the parent, then the child. Clicking an existing link removes it. You can also pick parents in the Node tab. Click a line to select it, Delete removes it. Cycles are rejected automatically.
Shortcuts
N new node · C connect · F fit · Del delete selection · Esc cancel · Ctrl+Z/Ctrl+Shift+Z undo/redo.
Effect syntax (used by the simulator)
Modifier x3 multiplies a currency's production; +1/s adds per second. Put the currency in "Target" (or write it in the modifier, e.g. x3 Points). Repeatable nodes apply their effect once per level. Anything else is kept as plain text for your own game.
Tools
Search (top-left) highlights nodes matching every word in the ID, name, description, type, #tag, effects or cost currency. Colour & tag are set per node in the Inspector. Variables tab: global constants for formulas. Formula boxes autocomplete (↑↓, Tab/Enter). Dev panel (Test mode): grant/set currencies, infinite resources, and a breakdown such as ×3 U1 … = total per second for the chosen currency. Buy max: Shift-click a repeatable, or choose it in Settings. Multi-select (editing): Shift-drag a box on the canvas, Shift-click nodes to add/remove, Ctrl+A for all; drag any selected node to move the group, Del deletes them, Ctrl+C / Ctrl+V copy and paste (links between copied nodes are kept; IDs written inside formulas or selectors are not rewritten).
Achievements, challenges & maths
Achievement: free; unlocks by itself once its parents are owned and its condition is true (points >= 1e6, b1 >= 10 && r1 > 0). Stays owned through resets. Challenge: click to enter (optionally resetting upgrades by ID); while active its Penalty rows apply (^0.5 = production to a power, x0.1, +-5/s); when the goal is met it completes permanently and its Effects become the reward. Click again to abandon. New formula tools: comparisons, if(cond, a, b) and softcap(x, start, power) (past start, growth is raised to power), e.g. effect x softcap(1+sqrt(honey), 1e6, 0.5). Node icons accept an emoji or an image URL. Updates per second is in Settings; the Dev panel can export/import a save string.
Blocking & disabling
Block buying: while a node is owned, nodes matching its IDs can't be bought (they show as locked); add "until" IDs and the block lifts once any matching node is owned, otherwise it is permanent. Disable properties: while owned, a node can switch off another node's Effects, Automation, Type-change rule, or, for Rebirth nodes, the Currency reset (name currencies, or blank = all) and Upgrade reset (IDs, or blank = all). Example: an upgrade with "Currency reset → R1" and value Points, Experience makes rebirths stop resetting those.
Automation & type changes
Automation Unlock / Perma-Automation Unlock nodes, once owned, buy every upgrade whose ID matches their field (U#) as soon as it is affordable; a delay in seconds slows it (0 = instant). Perma-Automation survives rebirth. Any node can also have "When owned: change type of nodes" — e.g. an owned prestige upgrade turning R12 into a Permanent Unlock so rebirths keep it. IDs: R12 = exactly that node, R# = letter R + digits.
Rebirth (reset layer)
Set a node's type to Rebirth (Reset). While simulating, click it once its Costs (the requirement, not spent) are met: the gain formula converts your whole current balance (rebirth_points = (points/100000)^0.5), adds it to that currency, then resets currencies and the upgrades/boards whose ID matches its “Reset upgrades of beginning ID of” field (U# hits U1, U12 but not UA1; blank = all). Kept: the gained currency, extra "keep" currencies, Permanent Unlock nodes, other Rebirth nodes and (optionally) root upgrades. Naming a node's exact ID in the reset field (e.g. R12) resets it even if it is permanent. Boards reset too. Put the formula here rather than in Effects.
Formulas
An effect modifier can be a formula (give it a Target currency). x2^level or a bare log10(points) multiplies the target; +sqrt(points) adds per second. Plain numbers (x2) still apply once per level; formulas are evaluated as written, so use level inside them. Operators + - * / % ^; functions log10 log2 ln log(x,base) exp sqrt cbrt abs floor ceil round min max pow clamp sin cos; constants pi e. Variables: currency names in lowercase (points, rebirth_points), level, time, and any node/board id (u7 = its level). Rebirth nodes also give s1_gain (for node S1): what a click would give right now, before its currency's multipliers — so +s1_gain/s generates 100% of a click's gain every second (+s1_gain*0.1/s for 10%). Tip: log10(points) is below 1 for fewer than 10 points — use max(1, log10(points)) to avoid slowing yourself.
Boards
Set a node's type to Board. When simulating, it unlocks once its parents are owned, then drains its currency (or tracks income) into a progress bar and levels up automatically; overflow carries over. "Needed for next level" is a formula of level. Stat lines are live formulas shown on the board (e.g. label Point Buff, formula 2^level, prefix x). Put the gameplay effect in Effects, e.g. target Points, modifier x2^level.
Numbers
Costs/rates accept 1e6 and suffixes: K, M, B, T, Qa (=Qd), Qi, Sx, Sp, Oc, No, Dc.
Log, projects & run saves
Log checks the whole tree as you edit: Syntax (formulas that can't be read), Logic (unknown names, missing currencies, upgrades that can never be bought) and Runtime (problems that appear while a Test run is going). Click an entry to jump to the node; nodes with a problem show a small dot. Projects (top bar, next to the name) are separate trees you can switch between at any time. Save run pauses and saves your progress to a file; Load run picks it up again later.
