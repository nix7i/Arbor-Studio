# Arbor Studio

A node-based visual designer built for creating, balancing, 
and simulating game progression systems. The software allows 
developers to map out upgrade paths, implement complex 
mathematical formulas for currency scaling, and configure 
mechanics like automation, milestone unlocks, and rebirth 
resets. With an integrated real-time simulator, users can 
instantly test game balance and export the structured tree data 
directly into their project workflows.

## System Requirements & Prerequisites

### Minimum Requirements
- **Operating System:** Windows 10 (64-bit) or Windows 11
- **Environment:** Local desktop execution environment (self-contained packaged build)

### Architecture Notes
- **Serverless Architecture:** No server-side code (PHP, Python, etc.) runs inside or is required by the app. All processing, graph evaluation, and simulations occur completely on the client side.
